# Sonsuz Döngüde Felsefe Yapan Bot

## Giriş (Ciddiye Alınması Gereken Bir Uyarı)

Bu repository, insanlık tarihinin en büyük varoluşsal sorununa çözüm üretmek amacıyla oluşturulmuştur. Çözüm üretmez. Sadece sorunu çoğaltır, süsler ve sonsuza kadar döndürür.

Bot, size rastgele felsefi söylemler üretir. Bunların %100'ü anlamsızdır. %0'ı doğrudur. Ama hepsi çok ciddi görünür.

## Özellikler

- Sonsuz döngüde çalışır (Ctrl+C yapana kadar, yapmazsanız ebediyet)
- Türkçe felsefi saçmalıklar üretir
- Ara sıra "Anladın mı?" diye sorar ve cevabınızı dinlemez
- CPU'nuzu ısıtmaz, ruhunuzu ısıtır
- Hiçbir şey yapmaz ama her şeyi yapmış gibi davranır

## Kurulum

```bash
git clone https://github.com/Tentivory/sonsuz-dongude-felsefe-yapan-bot.git
cd sonsuz-dongude-felsefe-yapan-bot
python3 felsefe_botu.py
```

Tebrikler. Artık varoluşunuz sorgulanıyor.

## Uyarı

Bu botu çalıştırmak önce eğlencelidir, sonra düşündürücüdür, sonra sizi odanızda tek başınıza otururken "ben kimim?" diye sormaya iter. Sorumluluk kabul etmiyoruz.
